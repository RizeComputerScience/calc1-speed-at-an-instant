# Calculus I: Speed at an Instant (interactive lesson)

A standalone interactive lesson page for Rize's Calculus I course (catalog code `MATHS I`), Unit 2: from average speed to the speed at one instant. No login and no backend; progress is saved in the browser's own `localStorage`.

**Live:** https://rizecomputerscience.github.io/calc1-speed-at-an-instant/

**Source and build record:** `projects/coursedev/CALC-I/interactive/unit2-speed-at-an-instant/` on Samuel's machine (`PLAN.md` is the design, `src/` the source, `build.py` the build, `history/` the reviews). `index.html` here is the built page, unchanged. It defines `window.__selfCheck()` for Rize's page-health monitor (`swachtel-dev/rize-interactive-health`).

Built October 2026 from the interactive-lessons kit (`toolkit/designing-the-learning-path.md`).
